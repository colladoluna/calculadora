# Calculadora en Python

Calculadora básica hecha en Python que se ejecuta desde la terminal.

## Tecnologías usadas

- Python 3

## Funcionalidades

- Suma, resta, multiplicación y división
- Control de errores: división entre cero y entradas no numéricas
- Menú en bucle hasta que el usuario decide salir

## Requisitos

- Tener Python instalado: https://www.python.org/downloads/
- No necesita ninguna librería adicional

## Cómo ejecutarlo

Desde la terminal:python calculadora.py

Desde Visual Studio Code:
- Abre el archivo `calculadora.py`
- Pulsa el botón Run de la esquina superior derecha
- O abre la terminal integrada y ejecuta `python calculadora.py`
